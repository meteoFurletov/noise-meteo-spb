# Валидация классификации устойчивости ERA5 v2 по радиозондам Voeikovo

## Постановка

Сопоставлены попарно по часам UTC значения числа Ричардсона, рассчитанного по реанализу ERA5 (конвейер v2, ячейка 60.00° с.ш., 30.75° в.д.), и независимо реконструированного по радиозондовым профилям станции Voeikovo (WMO 26063 до 2018-10-31, 26075 после; 59.952° с.ш., 30.707° в.д.). Слой расчёта Ri_b — 2 м → 100 м над уровнем поверхности; порог устойчивости 0.1, нижний порог квадрата сдвига 1.0 м²/с² (как в ERA5-конвейере).

Запусков с валидной парой: **4451** из 8036 запрошенных (охват 2014–2024 гг., два запуска в сутки, 00 и 12 UTC).

## Бинарная классификация (устойчиво / неустойчиво)

| | ERA5: неустойчиво | ERA5: устойчиво | всего |
|---|---|---|---|
| **зонд: неустойчиво** | 1824 | 1289 | 3113 |
| **зонд: устойчиво**   | 112 | 1226 | 1338 |
| **всего**             | 1936 | 2515 | 4451 |

- Совпадение классов: **68.5 %**
- Каппа Коэна: **0.402**
- Доля устойчивых случаев по зондам: 30.1 %; по ERA5: 56.5 %

## Корреляция непрерывных значений Ri_b

- Пирсон r = **0.413** (p = 0.00e+00); значения обрезаны до ±10 для подавления крайних выбросов.
- Спирмен ρ = **0.649** (p = 0.00e+00); ранговая, использует исходные значения без обрезки.

## Жёсткие критерии

- ❌ **Бинарное совпадение ≥ 70 %** — 68.5 %; целевое: ≥ 70 % (жёстко), ≥ 60 % (мягко)
- ✅ **Каппа Коэна ≥ 0.35** — 0.402; целевое: ≥ 0.35
- ✅ **Согласие JJA ≥ DJF** — JJA 78.5 % vs DJF 52.3 %; целевое: JJA ≥ DJF

## Замечания

- Согласование во времени: оба источника часовые в UTC; зондовый запуск относится к ближайшему часу ERA5 с допуском ±45 мин.
- Окно высот идентично у обоих источников (2 м → 100 м над поверхностью), что устраняет систематический сдвиг, наблюдавшийся в v1 при использовании разных опорных уровней.
- Хвосты Ri_b у обоих источников экстремальные при слабом сдвиге; именно поэтому первичной метрикой является бинарная классификация, а Пирсон рассчитан на обрезанных значениях.
