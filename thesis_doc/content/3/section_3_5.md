# §3.5 — Алгоритм построения климатологической справочной таблицы

В настоящем подразделе формализуется алгоритм построения посекторной климатологической справочной таблицы $p_{\text{благ}}$ — методологического сердца работы. Изложение ведётся на архитектурном уровне: фиксируется последовательность этапов, контракты между ними, методологические выборы внутри каждого этапа и структура итогового выходного артефакта. Полная программная реализация пайплайна с описанием модулей и интерфейсов — §4.1; численные результаты — §§4.3–4.6.

## 3.5.1 Структура алгоритма

Алгоритм построения справочной таблицы состоит из пяти последовательных этапов с явными программными контрактами между ними:

1. **Загрузка данных ERA5.** Вход — конфигурация домена и временного горизонта; выход — кэш `era5_spb_v2.zarr` (полный набор переменных из §3.4.4, индексированный по координатам *(time, latitude, longitude)*); методологические выборы — выбор датасетов CDS и состав переменных (§3.4).
2. **Классификация устойчивости.** Вход — `era5_spb_v2.zarr`; выход — кэш `stability_v2.zarr` с тремя независимыми классификаторами для каждой пары *(ячейка × час)*; методологические выборы — формулы и пороги триангуляции (§3.5.2).
3. **Посекторный признак благоприятности.** Вход — `stability_v2.zarr` плюс приземные ветровые компоненты $u_{10}, v_{10}$; выход — кэш `favorable_v2.zarr` с бинарным признаком для каждой пары *(ячейка × час × сектор)*; методологические выборы — каскадная подстановка термического канала (§3.5.3) и операциональный вид критерия благоприятности (§3.5.4).
4. **Климатологическая агрегация.** Вход — `favorable_v2.zarr`; выход — два NetCDF-файла справочной таблицы (`p_favorable_spb.nc` и `p_favorable_cnossos.nc`); методологические выборы — сезонно-периодная сетка агрегации (§3.5.5) и параллельное сохранение двух каналов (§3.5.6).
5. **Валидация.** Двухканальная: термическая по аэрологическим зондированиям станции Воейково и ветровая по наземным наблюдениям станции WMO 26063; описание материала, парных выборок и результатов — §4.7 и §4.8.

Принципиальное свойство архитектуры — *явное разделение зон ответственности*: каждый этап имеет один входной артефакт, один выходной артефакт и одну группу методологических выборов, локализованных внутри этапа. Это обеспечивает воспроизводимость пайплайна, возможность независимой замены этапов (например, использование альтернативного классификатора устойчивости без перестройки этапов 1, 3 и 4) и упрощение QC: проверки целостности выполняются на границе между этапами, а не как сквозная процедура.

## 3.5.2 Классификация устойчивости: триангуляция трёх независимых методов

На этапе 2 параллельно рассчитываются три классификатора устойчивости атмосферы; каждый из них имеет независимые входные переменные ERA5, независимую физическую логику и независимые границы применимости (теоретическое обоснование триангуляции — §2.4.4; методологическое решение — §3.1.8).

**Объёмное число Ричардсона $Ri_b$ (основной канал).** Безразмерное отношение плавучестной генерации к сдвиговой диссипации, вычисляемое между двумя уровнями над поверхностью — нижним (приземный воздух, $T_{2\text{м}}, u_{10}, v_{10}$) и верхним фиксированным (100 м над поверхностью; $u_{100}, v_{100}$, температура — интерполяция термического профиля с pressure-level уровней 975 и 950 гПа). Полная формула расчёта приведена в §4.3.1. Порог устойчивости — $Ri_b \geq 0{,}1$, согласно хрестоматийной таблице соответствия классов устойчивости и значений $Ri_b$ для $z_0 \sim 0{,}1$ м (§2.3.5). Принципиальное методологическое решение — фиксированно-высотная верхняя точка (10 м → 100 м над поверхностью) вместо изобарической поверхности 1000 гПа, устраняющая подповерхностный артефакт в 27,49 % часов климатологии СПб (полное обоснование — §3.4.5). Дополнительное операциональное условие — пороговое значение квадрата сдвига $S^2 = (\Delta u)^2 + (\Delta v)^2 \geq 1{,}0$ м²/с²: при меньших значениях сдвига знаменатель формулы $Ri_b$ численно неустойчив, и значение помечается как $\mathrm{NaN}$ для каскадной подстановки (§3.5.3).

**Обратная длина Монина–Обухова $1/L$.** Прямая физическая характеристика отношения плавучестной и сдвиговой генерации турбулентности в приземном слое (см. §2.4.2). В работе $1/L$ вычисляется через канонические переменные ECMWF: *мгновенный* приповерхностный поток явного тепла `instantaneous_surface_sensible_heat_flux`, *мгновенный* поток влаги `instantaneous_moisture_flux`, и фрикционная скорость $u_*$, восстанавливаемая из мгновенных компонент турбулентного приземного напряжения. Принципиальное методологическое условие — использование *мгновенных*, а не аккумулированных полей: аккумулированные потоки (`surface_sensible_heat_flux`, `surface_latent_heat_flux`) в ERA5 являются интегралом за прошедший прогнозный час и не соответствуют мгновенному значению, требуемому для расчёта мгновенного $L$. Аналогично, фрикционная скорость $u_*$ вычисляется *de novo* из компонент турбулентного напряжения, а не извлекается из ERA5-переменной `friction_velocity` (`zust`), которая в IFS постпроцессинге проходит через дополнительную фильтрацию и не строго соответствует физическому $u_*$ в формуле $L$. Пороги устойчивости — два уровня: $1/L \geq 0{,}05$ м⁻¹ (строгий) и $1/L \geq 0{,}01$ м⁻¹ (умеренный); сохранение обоих позволяет исследовать чувствительность климатологии к выбору порога (§3.5.7).

**Pasquill–Тёрнер (вариант Тёрнера).** Классическая схема Pasquill–Gifford в модификации Тёрнера, заменяющей качественную инсоляцию количественным дескриптором прямой солнечной радиации (см. §2.3.4). В работе используется ERA5-переменная `fdir` (прямая солнечная радиация на горизонтальной поверхности, приведённая к мгновенной плотности потока) в качестве дневного дескриптора инсоляции и `tcc` (общая облачность) в качестве ночного дескриптора дальневолнового баланса. Класс устойчивости определяется по приземному ветру $|U_{10}|$ и дескрипторам инсоляции / облачности через стандартную таблицу Pasquill–Тёрнера; устойчивыми считаются классы $E, F, G$. Pasquill–Тёрнер — единственный из трёх классификаторов, доступный во *всех* часах ансамбля без условий определимости, что делает его естественным fallback'ом в каскадной подстановке (§3.5.3) и одновременно основой CNOSSOS-верного канала (§3.5.6).

**Обоснование триангуляции.** Принципиальное методологическое содержание этапа — параллельный расчёт всех трёх классификаторов и сохранение каждого как независимого выходного поля в `stability_v2.zarr`. Триангуляция не является механизмом выбора «единственно правильного» классификатора; она фиксирует расхождение между классификаторами как самостоятельный климатологический результат, обоснованный документированным в литературе систематическим несогласием классификаторов в приземных условиях [Одинцов и др., 2025; Гладких и др., 2025]. Численные результаты согласования и расхождения трёх классификаторов в климатологии СПб — §4.3.

## 3.5.3 Каскадная подстановка: основной канал «Ri_b + Pasquill–Тёрнер»

Объёмное число Ричардсона $Ri_b$ как основной классификатор имеет одно операциональное ограничение — в часы малого ветрового сдвига ($S^2 < 1{,}0$ м²/с²) знаменатель формулы численно неустойчив, и значение $Ri_b$ помечается как $\mathrm{NaN}$. Чтобы термический канал не терял эти часы из ансамбля, в основной канал работы введена *каскадная подстановка* классификатора Pasquill–Тёрнера в качестве fallback'а:

$$\text{favorable}^{\text{thermal}}_{Ri+\text{каскад}}(t, c) \;=\; \begin{cases} \mathbf{1}\big[ Ri_b(t, c) \geq 0{,}1 \big], & Ri_b(t, c) \neq \mathrm{NaN}, \\[4pt] \mathbf{1}\big[ \text{Pasquill}(t, c) \in \{E, F, G\} \big], & Ri_b(t, c) = \mathrm{NaN}. \end{cases} \tag{3.7}$$

Выбор Pasquill–Тёрнера (а не $1/L$) в роли fallback'а обоснован тремя соображениями. Во-первых, *численная устойчивость в штилевых условиях*: при малом сдвиге, в которых $Ri_b$ помечается NaN, $1/L$ также страдает кубическим усилением неопределённости через $u_*^3$ (§2.4.5, категория (1)), в то время как Pasquill–Тёрнер опирается на качественные дескрипторы и остаётся определимым во всех часах. Во-вторых, *согласие средней доли устойчивых случаев с зондовой эмпирической истиной*: контрольное сопоставление с аэрологическими зондированиями Воейково (§4.7) даёт долю устойчивых часов по Pasquill ≈ 28 % при эмпирически наблюдаемой доле ≈ 30 %, что укладывается в естественную погрешность классификации (расхождение менее 2 п.п.). В-третьих, *методологическая совместимость с CNOSSOS-EU*: Annex II §2.5.6 Директивы (ЕС) 2015/996 предписывает классификацию устойчивости именно по Pasquill–Тёрнеру; выбор того же классификатора в роли fallback'а обеспечивает прямую сопоставимость основного и CNOSSOS-верного каналов работы (§3.5.6, §3.6.3).

Доля часов ансамбля 2014–2024 гг., в которых сработала каскадная подстановка ($Ri_b = \mathrm{NaN}$), составляет 11,2 % полного объёма (см. §4.3.2). Прозрачное знание этой доли и её распределения по сезонам — самостоятельный QC-результат, фиксируемый в выходной справочной таблице (§3.5.7).

## 3.5.4 Посекторный признак благоприятности

Полный признак благоприятности — операциональная конкретизация формулы (3.2) §3.3.1 после подстановки термического канала (3.7) — записывается как:

$$\text{favorable}(t, c, \theta) \;=\; \mathbf{1}\big[ u_\parallel(t, c, \theta) \geq 2{,}0\ \text{м/с} \big] \;\lor\; \text{favorable}^{\text{thermal}}_{Ri+\text{каскад}}(t, c). \tag{3.8}$$

Ветровой компонент использует проекцию приземного ветра на азимут распространения:

$$u_\parallel(t, c, \theta) \;=\; |U_{10}(t, c)| \cdot \cos\!\big( \theta_{\text{ISO}}(\theta) - \theta_{\text{wind\_to}}(t, c) \big),$$

где $\theta_{\text{ISO}}$ — центральный азимут сектора в конвенции ИСО 9613-2 (направление, в котором рассматривается распространение звука к приёмнику; см. Решение 3.1.9 и Приложение В); $\theta_{\text{wind\_to}}$ — направление вектора ветра в той же конвенции «куда дует», вычисляемое из ERA5-компонент $(u_{10}, v_{10})$ через стандартное преобразование $\theta_{\text{wind\_to}} = \text{atan2}(u_{10}, v_{10})$. Сетка азимутальных секторов — 18 равных интервалов шириной 20° (CNOSSOS-EU стандарт; центры на 0°, 20°, 40°, …, 340°).

Чувствительность бинарного признака к выбору порога попутного ветра $u_{\text{thr}} = 2{,}0$ м/с — содержание §4.4: в диапазоне порога $u_{\text{thr}} \in [1{,}0; 3{,}0]$ м/с пиковое направление сигнала $p_{\text{благ}}^{\text{wind}}(\theta)$ остаётся устойчивым, что эмпирически подтверждает робастность направленной структуры результата к выбору порога.

## 3.5.5 Временна́я и пространственная агрегация

Климатологическая агрегация почасового признака (3.8) выполняется по двум измерениям — сезонному и суточному:

- **Сезонное.** Четыре стандартных метеорологических сезона: зимний DJF (декабрь–февраль), весенний MAM (март–май), летний JJA (июнь–август), осенний SON (сентябрь–ноябрь).
- **Суточное.** Три периода Lden по Директиве 2002/49/EC: дневной 07:00–19:00, вечерний 19:00–23:00, ночной 23:00–07:00 в местном (московском) времени UTC+3. Сетка Lden-периодов согласована с разделением день/ночь в СанПиН 1.2.3685-21 (§1.1.4).

Пространственной единицей агрегации остаётся ячейка ERA5 0,25° (Решение 3.1.6); агрегация по двум временны́м измерениям выполняется независимо в каждой из 35 ячеек домена СПб. Климатологическая вероятность для каждой комбинации индексов вычисляется как эмпирическое матожидание индикатора:

$$p_{\text{благ}}(c, \theta, s, \tau) \;=\; \frac{1}{N(c, s, \tau)} \sum_{t \in T(c, s, \tau)} \text{favorable}(t, c, \theta),$$

где $T(c, s, \tau)$ — множество почасовых отметок ячейки $c$, относящихся к сезону $s$ и периоду $\tau$, а $N(c, s, \tau) = |T(c, s, \tau)|$ — соответствующее число выборок (порядка 8 000 часов на бин). Полная размерность справочной таблицы — $35 \times 18 \times 4 \times 3 = 7\,560$ скалярных значений на канал.

## 3.5.6 Двухканальный выход: основной и CNOSSOS-верный

Принципиальная методологическая особенность v2-спецификации настоящей работы — параллельное производство двух согласованных версий справочной таблицы, различающихся методом классификации термического канала:

- **Основной канал, файл `p_favorable_spb.nc`.** Термический канал — каскад «$Ri_b$ + Pasquill–Тёрнер» по формуле (3.7); ветровой канал — стандартный по (3.8). Этот канал использует физически прямую характеристику стратификации ($Ri_b$ как отношение плавучестной и сдвиговой генерации) и представляет *методологическое расширение* CNOSSOS-EU за счёт замены качественной классификации Pasquill–Тёрнера на количественный $Ri_b$ там, где последний определим (88,8 % часов ансамбля). Назначение — основной операциональный артефакт для практики расчёта $C_{met}$ в климатологии Санкт-Петербурга.

- **CNOSSOS-верный канал, файл `p_favorable_cnossos.nc`.** Термический канал — строго по Pasquill–Тёрнеру, без каскада: $\text{favorable}^{\text{thermal}}_{\text{PG}}(t, c) = \mathbf{1}\big[\text{Pasquill}(t, c) \in \{E, F, G\}\big]$ во всех часах ансамбля; ветровой канал идентичен основному. Этот канал представляет *прямую реализацию* CNOSSOS-EU методологии в смысле Annex II §2.5.6 Директивы (ЕС) 2015/996. Назначение — обеспечение прямого методологического сопоставления климатологии Санкт-Петербурга с зарубежными региональными реализациями CNOSSOS-EU (численное сопоставление двух каналов — §4.9).

Двухканальный выход — самостоятельный методологический результат работы: одновременная публикация физически прямого расширения и CNOSSOS-верной реализации, на едином исходном датасете ERA5, обеспечивает читателю и оппоненту возможность непосредственного количественного сопоставления методологического эффекта замены классификатора без необходимости перерасчёта по альтернативной методике. Принципиальное позиционирование обоих каналов относительно международной практики — §3.6.

## 3.5.7 Структура выходного файла и контроль качества

Каждый из двух выходных файлов сохраняется в формате NetCDF-4 с метаданными в спецификации CF-1.10. Координаты массива: *(latitude, longitude, sector, season, period)* размерностей $(5, 7, 18, 4, 3)$ соответственно. Сохраняемые переменные:

- `p_favorable` — совокупная вероятность благоприятности (логическое ИЛИ ветрового и термического условий по (3.8)); главная операциональная величина каждого файла.
- `p_favorable_wind` — посекторная вероятность по ветровому условию изолированно; используется для анализа направленной структуры сигнала и для декомпозиции вкладов двух механизмов (§4.4.4).
- `p_favorable_thermal_Ri` — термический компонент по $Ri_b$ без каскада (только часы с $Ri_b \neq \mathrm{NaN}$); вариант 1 для анализа чувствительности.
- `p_favorable_thermal_PG` — термический компонент строго по Pasquill–Тёрнеру (классы $E, F, G$); вариант 2, идентичен термическому каналу CNOSSOS-верного файла.
- `p_favorable_thermal_invL_mod`, `p_favorable_thermal_invL_strict` — термический компонент по обратной длине Монина–Обухова с умеренным ($1/L \geq 0{,}01$ м⁻¹) и строгим ($1/L \geq 0{,}05$ м⁻¹) порогами; варианты 3 и 4 для анализа чувствительности.
- `p_favorable_thermal_Ri_strict` — термический компонент по $Ri_b$ со строгим порогом $Ri_b \geq 0{,}25$, соответствующим критическому значению Майлза–Хауарда (§2.3.3); вариант 5 для анализа чувствительности.
- `n_samples` — число валидных часов в выборке для каждой комбинации индексов *(ячейка × сезон × период)*; основной QC-показатель статистической мощности бина.

Глобальные метаданные файла включают идентификатор источника входных данных (ERA5 CDS), временной горизонт 2014–2024, методологическую ссылку на настоящую работу с указанием версии пайплайна, явную декларацию конвенции направления ИСО 9613-2 (см. Приложение В) и параметрические значения порогов классификации устойчивости.

Запланированные QC-проверки для каждого из двух выходных файлов: (1) контроль числа валидных часов $n_{\text{samples}}$ во всех бинах относительно минимального асимптотического порога $n > 30$; (2) внутренняя согласованность — нестрогое неравенство $p_{\text{favorable}} \leq p_{\text{favorable\_wind}} + p_{\text{favorable\_thermal}}$, гарантируемое логикой ИЛИ; (3) отсутствие пропусков в массиве `p_favorable` в пределах домена; (4) физическая правдоподобность диапазона значений $p_{\text{благ}} \in [0; 1]$. Эмпирические результаты QC-проверок — §4.6.
